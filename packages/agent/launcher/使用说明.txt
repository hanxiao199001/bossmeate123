BossMate 本地发布 Agent — 客户使用说明（3 步）

──────────────────────────────────────────
第 1 步：安装 Node.js（只需一次）
  打开 https://nodejs.org ，下载 LTS 版，一路“下一步”装好。
  （已经装过的可跳过）

第 2 步：放入配对配置（可选，但更省事）
  在 BossMate 网页：设置 → 本地发布 Agent → “下载客户配置”，
  把下载到的 bossmate.cfg 覆盖到本文件夹里（替换同名文件）。
  这样就不用手动输配对码了。
  （没有也行，直接做第 3 步，双击后按提示手动输入服务器地址和配对码。）

第 3 步：双击启动
  · Mac：双击  start-agent.command
  · Windows：双击  start-agent.bat
  首次会自动安装运行环境 + 配对 + 弹出浏览器让你扫码登录账号；
  之后保持窗口开着、电脑不要休眠，就会自动领任务发布。

──────────────────────────────────────────
常见问题
  · 停止：在窗口里按 Ctrl + C。
  · 配对码 10 分钟过期：过期就回网页重新下载 bossmate.cfg 再双击。
  · 账号登录失效：关掉窗口重新双击即可重新扫码。
  · Mac 提示“无法打开，因为来自身份不明的开发者”：
    右键点 start-agent.command → 选“打开” → 再点“打开”。
