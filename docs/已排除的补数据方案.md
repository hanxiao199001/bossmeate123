## 4. rich 优先（按 dataSupply 分级优先选刊）

| | |
|---|---|
| **方案** | 选刊器降级链里加 dataSupply 优先级，优先选数据完整的刊，以提升 dataAccuracy 得分 |
| **封闭理由** | **两头都不成立** —— 一头没有提升空间，另一头没有可优先的对象 |
| **封闭日期** | 2026-08-24 |

支撑数据（近 14 天，按账号 scope 分组的实际用刊）：

```
scope            rich    medium   sparse
international   47.3%    18.7%    34.1%    ← 已经以 rich 为主，提升空间小
both            28.1%    12.5%    59.4%
domestic        32.5%     6.5%    61.0%
```

全库 10 个学科 rich 合计 3897 本，**国内刊只有 30 本**：

```
学科          rich总   国内刊   国内占比
medicine       1106      12      1.1%
psychology      247       1      0.4%
environment     338       0      0.0%
...（多数学科 0.0%）
```

三条封闭理由，任一独立成立：

1. **international 已经在用 rich**（47.3%），加优先级提升空间小
2. **domestic 没有 rich 可优先**（全库国内 rich 仅 30 本）
3. 🔴 **「按 dataSupply 优先」在实现上等于「按国际刊优先」** ——
   中文公众号推 Elsevier/Springer 英文刊，这是**内容定位变更**，不是技术优化

补充观察：**优先级治不了冷却**。international 那 34.1% 的 sparse，
是对口 rich 在 15 天冷却期内选不出来才退化的；加优先级只会让它更早耗尽 rich、更快退回 sparse。

| | |
|---|---|
| **方案** | 给 5 个 `disciplines` 为空的账号配 psychology，利用其 rich 池（247 本，能撑 284 天） |
| **封闭理由** | **前提不成立** —— 「5 个号闲置」是错的 |
| **封闭日期** | 2026-08-24 |

支撑数据（近 14 天进箱）：

```
号                    disciplines      scope           近14天进箱
老韩很野vibecoding    []               both               28
学术研途鉴            []               international      28
学术指南卡卡          []               domestic           28

学术河洛志            ["education"]    domestic           28
论文解忧栈            ["education"]    international      25
```

**`disciplines` 为空的 5 个号全部满产 27-28 篇/14 天。**
「空定位」不等于「闲置」——它们靠 `scope` 约束在跑，且是主力。
给它们配 psychology 会**改变现有产出**，不是「填空」。

唯一真闲着的 `Paper咨询与发表` 断供 27 天，但根因是配对/凭证故障
（`account_supply_starved` 正为它而喊），配 psychology 不会让它开始出内容。

另：psychology 的 247 本 rich 里国内刊只有 1 本 —— 即使配上，拿到的也是国际刊（同第 4 条）。

## 仍然开着的一条：期刊官网发现

**不在本文档的排除范围内**，但要知道它的上限：

- 实测抽样命中率约 **40%**（n=5：大学主办 2/2 命中，部委/学会主办 2/2 落在知网门户）
- 决定成败的是**主办单位类型**，不是学科
- education 149 本国内刊里，刊名可推断为大学/学院主办的仅 **12.1%**（下限，刊名推断会漏）
- 已产出可复用件：`services/journals/site-discovery-filter.ts`（中介站过滤器，20/20 测试绿）

🔴 关键结构性障碍（三条，实测）：

1. **搜索结果被论文中介污染** —— 官网发现本身就是难题，不是抓取难题
2. **相当一部分「官网」托管在 `cbpt.cnki.net`** —— 数据在、栏目清晰，但撞硬约束
3. **有真官网的也未必可解析** —— 实测《中国空间科学技术》目录页是 JS 渲染，
   静态抓取只拿到 `{{classify2}}` 模板占位符

## 附：中介站识别的两条特征（实测归纳，已落代码）

**① 固定域名黑名单** —— 大站，一个域名服务所有刊（39 个，见 `site-discovery-filter.ts`）

**② 标题模板 + 域名命名规律** —— **每刊一域名**的中介网络，域名黑名单拦不住：

```
www.cdtyxyxbzz.cn   《成都体育学院学报》…投稿_期刊论文发表|版面费|电话|编辑部
www.zgdhjyzz.cn     《中国电化教育》…投稿_期刊论文发表|版面费|电话|编辑部
www.tsgxyjzzs.cn    《图书馆学研究》…投稿_期刊论文发表|版面费|电话|编辑部
```

域名规律：刊名拼音缩写 + `zz`/`zzs` + `.cn`。**单看域名像官网，单看标题才露馅。**

> **一个特征拦不住的，往往不是因为特征错了，而是因为对方的变化维度和你的判据不在同一个维度上。**
