# BossMate 客户开通 SOP

> 给一个新客户从零开通到每天自动出内容的标准流程。同行客户(学术服务赛道)走完即可用;跨行业客户额外走"企业画像向导"。全程约 30 分钟。

---

## 开通前准备(向客户要的材料)

- 客户公司**官网链接 / 产品介绍 / 已有公众号历史文章**(用于企业画像,跨行业必需)
- 客户要运营的**各平台账号**:公众号(AppID+AppSecret 或扫码)、视频号、抖音号
- 老板问卷答案(5 题:卖什么 / 谁买 / 客户常问什么 / 最想被记住哪点 / 不能碰什么)
- 套餐约定:月文章量、月视频量、账号数、服务期限

---

## 步骤一:建租户 + 配套餐

1. 为客户公司创建独立租户(一家公司 = 一个租户,数据互相隔离)。
2. 配套餐:`PATCH /admin/tenant-billing/<租户id>`
   ```json
   { "plan": "basic", "expiresAt": "2026-12-31",
     "monthlyArticleQuota": 300, "monthlyVideoQuota": 60, "accountLimit": 10 }
   ```
   到期或超量会自动拦截生成。**不配 = 不限**(测试期可不配)。

## 步骤二:接入账号

1. 公众号:「账号」页添加 → 填 AppID/AppSecret → 验证通过。
   - 未认证订阅号 = `draft_only`,只能进草稿箱人工群发(正常,风险可控)。
2. 视频号 / 抖音号:「账号」页扫码登录 → 在**客户电脑**装本地 Agent。
   - 客户电脑装 Agent:`pair` 配对 → `install-service` 装常驻(开机自启,Mac/Windows 都支持)。
   - 配对码在「设置 → 本地发布 Agent」生成。

## 步骤三:定位(二选一)

### A. 同行客户(学术服务)— 手动配,最快
1. 「账号」页给每个号点「领域」→ 多选学科(医学/心理/教育…)。
2. 给每个号点「人设·风格」→ 填一段人设;有爆款文就贴范文点「提炼风格画像」。

### B. 跨行业客户 — 走开通向导(自动)
1. 用**客户账号登录**,进「客户开通」页。
2. 第①步:贴公司资料 + 答老板问卷 → 提炼企业画像。
3. 第②步:一键推导账号定位(自动给每号分角色 + 写人设)。
4. 第③步:生成 50 条选题池。
5. 完成后回「账号」页微调领域定位。

## 步骤四:配每日生成 + 开自动分发

1. 配每日生成配额(按类型:国内/国外/盘点,各几篇、覆盖哪些学科)。
2. 设生成/分发时间:「今日」页右上角 ⏰(如生成 04:00、分发 08:00)。
3. 开「每日自动分发」开关。

## 步骤五:验收跑通一轮

1. 手动触发一次生成 → 「今日」页看到内容按账号分好、互不重复。
2. 内容进公众号草稿箱 → 抽查质量(每号风格应不同、都在自己领域)。
3. 抖音任务:Agent 弹通知 → 客户点发布。
4. 发布后:运营把各平台阅读量填回「今日」页「填数据」→ ROI 卡出数。

---

## 已知卡点(开通时容易踩)

| 卡点 | 表现 | 处理 |
|---|---|---|
| 公众号被限接口 | 批量发布报 `50002 user limited` | 该号违规/认证过期,登录 mp.weixin.qq.com 查,恢复前停用该号 |
| 账号没装 Agent | 视频号/抖音任务领不到 | 客户电脑装 Agent 并 `install-service` |
| 跨行业每日不出题 | 自动生成走期刊库,吃不到选题池 | **当前限制**:跨行业先手动从选题池挑题;选题池接每日管线在排期 |
| 生成被拦 | 报"已达套餐上限" | 套餐配额满,加购或调高配额 |
| 内容撞车 | 多号发相似内容 | 确认用「每号独家」模式 + 各号领域定位不同 |

---

## 开通完成检查清单

- [ ] 租户已建、套餐已配
- [ ] 所有账号已接入并验证(公众号 API / 视频号抖音扫码 + Agent 常驻)
- [ ] 每个号有领域定位 + 人设(同行手配 / 跨行业向导)
- [ ] 每日生成配额已配、生成/分发时间已设、自动分发已开
- [ ] 跑通一轮:生成不撞车 → 进草稿 → 抖音点发布 → 填数据出 ROI
